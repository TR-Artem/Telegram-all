# Мониторинг сайтов + алерты в Telegram

Сайт: https://tr-artem.github.io/Telegram-all/

Сервис следит за списком сайтов: каждые 30 минут открывает каждый адрес, записывает код ответа,
время ответа и срок действия SSL-сертификата. Если сайт не открылся две проверки подряд — приходит
сообщение в Telegram. Когда сайт снова заработал, приходит отдельное сообщение с длительностью
простоя: «лежал 2 ч 14 мин». Владелец узнаёт о падении в течение получаса, а не от клиента через
неделю.

React + TypeScript + Vite. Страницы: сводка по сайтам, страница сайта с историей проверок,
«О проверке». Публикация на GitHub Pages.

## Что показывает

- сводка: какой сайт открывается, доступность за 30 дней, среднее время ответа, дни до истечения SSL;
- страница сайта: история проверок за сутки, код ответа и время каждой проверки, SSL;
- алерт в Telegram: одно сообщение на переход состояния, со второй ошибки подряд — без ложных
  тревог и без спама;
- предупреждение по SSL за 14 и 7 дней до истечения сертификата;
- предупреждение, если сайт отвечает дольше 3 секунд;
- недельный дайджест по понедельникам: доступность и среднее время по каждому сайту.

## Запуск

```
npm install
npm run dev        # http://localhost:5173/Telegram-all/
npm run build && npm run preview
node scripts/check.mjs   # ручная проверка сайтов
TELEGRAM_DRY_RUN=1 DIGEST_FORCE=1 node scripts/check.mjs   # дайджест без отправки в Telegram
```

## Публикация

- Settings → Pages → Source: GitHub Actions.
- Проверка (`check.yml`, каждые 30 минут) сохраняет `public/data/results.json` и публикует сайт.
- Ручной запуск: Actions → «Проверка сайтов каждые 30 минут» → Run workflow.
- Секреты репозитория: `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`. Без них сообщения не отправляются.

## Список сайтов

`public/data/sites.json` — демонстрационный набор: три собственных проекта и два открытых сайта.
Один адрес намеренно недоступен, чтобы на сводке была видна сработка. Подключение своих сайтов —
замена этого файла (`id` латиницей, название, адрес).

## Скриншоты

`docs/screenshots/` — сводка с одним недоступным сайтом, история проверок, страница «О проверке».
Скриншот сообщения бота в Telegram добавляется после первого реального падения: он подтверждает,
что алерт уходит, а не только что он описан в коде.
